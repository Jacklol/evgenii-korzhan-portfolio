# Evgenii Korzhan - React Native Portfolio

Static portfolio website for React Native client calls.

## Pages

- `index.html` - portfolio landing page with project cases.
- `resume.html` - online CV.
- `assets/evgenii-korzhan-react-native-cv.pdf` - downloadable one-page CV.

## Deployment

This repository is configured for GitHub Pages through GitHub Actions.

After every push to `main`, the workflow in `.github/workflows/pages.yml` publishes the repository root as the website.
